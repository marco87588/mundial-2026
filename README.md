# ⚽ Copa Mundial FIFA 2026 - Sitio Web

## 📋 Descripción del proyecto
Este es un sitio web informativo sobre la Copa Mundial de la FIFA 2026 que se celebrará en México, Estados Unidos y Canadá. La página está diseñada para presentar información clave del evento de forma clara y accesible.

El sitio cuenta con 5 secciones:
- **Inicio**: Información general del mundial
- **Anfitriones**: Detalles sobre los 3 países sede
- **Estadios**: Principales estadios donde se jugarán los partidos
- **Países**: Lista de selecciones clasificadas al torneo
- **Datos curiosos**: Información relevante sobre el mundial 2026

## 🛠️ Herramientas y tecnologías utilizadas
- **HTML5**: Estructura de las 5 páginas del sitio
- **Github**: Control de versiones y alojamiento del código
- **Github Pages**: Despliegue del sitio web en vivo
- **Acode**: Editor de código usado para el desarrollo en móvil

## 📱 Características
- Diseño 100% responsive: se adapta a celular, tablet y computadora
- Navegación simple mediante menú con enlaces entre páginas
- Interfaz limpia con los colores representativos del mundial
